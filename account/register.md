# Inscription

La création d'un compte est gratuite et prend moins de 2 minutes. Une fois inscrit, vous accéderez au dashboard pour générer vos clés API et activer votre compte business.

![Page d'inscription d'Intram](<../.gitbook/assets/Capture d’écran 2022-06-18 à 07.41.37.png>)

## Étapes

1. Rendez-vous sur [https://app.intram.org/register](https://app.intram.org/register).
2. Remplissez le formulaire avec les informations demandées (nom, email, mot de passe).
3. Lisez attentivement les conditions d'utilisation — plusieurs règles s'appliquent à tout marchand enregistré sur la plateforme.
4. Validez votre inscription.
5. Connectez-vous à votre compte sur [https://app.intram.org](https://app.intram.org) avec l'email et le mot de passe choisis.

## Et après ?

Votre compte utilisateur est créé, mais vous ne pouvez **pas encore encaisser de paiements**. Pour activer la production, il faut :

1. [Activer votre compte business](account-activation.md) — fournir les pièces justificatives demandées.
2. Récupérer vos [clés API](../README.md#récupérer-vos-clés-api) depuis le menu **Développeurs**.
3. Intégrer l'API : [SDK et clients](../api-index.md) ou [Merchant API v1](../merchant-api/README.md).

{% hint style="danger" %}
Tant que votre compte business n'est pas validé, vos clés `LIVE` ne fonctionneront pas. Vous pouvez en revanche utiliser librement les clés `SANDBOX` pour développer et tester.
{% endhint %}

## Problème de connexion ?

* Vérifiez l'email de confirmation reçu après l'inscription (regardez aussi vos spams).
* Mot de passe oublié : utilisez le lien "Mot de passe oublié" sur [la page de login](https://app.intram.org/login).
* Si rien ne fonctionne, contactez le support depuis le formulaire en pied de page du site.
